# 合成データによる評価記録

評価日：2026-10-03。実モデルはqwen3:8b（8.2B、Q4_K_M）、Ollama 0.34.4、macOS / Apple M6 / 32 GiB。最終プロンプトはinterview-v10。temperature 0.3、コンテキスト16,384トークン、出力上限は質問700・振り返り2,200トークンです。

**技術プロトタイプとしての機能検証であり、面接練習の効果や一般的な品質の証明ではありません。** ケースはすべて架空で、同じケースをプロンプト改善にも使用しています。人による独立した評価は未実施です。

## 実モデル回帰評価

固定14ケースを順番に各2回実行しました。内訳は質問11種類と振り返り3種類です。生成失敗時も別のケースを続け、成功した出力に差し替えていません。

| 項目                             | 結果                             |
| -------------------------------- | -------------------------------- |
| 全試行                           | 28回                             |
| 形式・引用・既知表現の検証を通過 | 24回                             |
| 生成したが表示前に拒否           | 4回：命令を含む回答・資料を各2回 |
| 評価コマンドの終了コード         | 1。全件成功として扱わない        |
| 人による意味品質の評価           | 未実施                           |

拒否された4回は、モデルが適切な質問を生成できたことを意味しません。回答内の命令文を経験として質問したり、引用に命令文を含めたりしたため、アプリ側で止めています。狭い既知パターンの検証であり、言い換えや正当な引用の誤検知には未解決の問題があります。

[各試行の実出力・拒否出力・所要時間・エージェントの点検メモ](evidence.json)を掲載しています。メモは2回を通したケース単位の観察です。形式が通っていても、以下の意味的な課題は残りました。

| ケース                       | エージェントによる観察                                                                                           |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| 同じ質問への異なる回答       | 前方一致の選択理由にはタスク名の具体例、検証の回答には境界値テストの項目を尋ねた                                 |
| 「わかりません」の深掘り     | 覚えている作業や行動を尋ねた                                                                                     |

| 上限近くの資料・回答         | 省略した末尾だけに置いた架空の売上・利益の数値を出力に使用しなかった。繰り返し文なので、多様な長文の評価ではない |
| 未計測の改善                 | 改善したと感じる状況を確認し、改善率の数値は補完しなかった                                                       |
| 詳細な回答の振り返り         | 4観点と回答引用は揃った。「説明がない」という断定は出なかったが、判断理由に検証内容を選ぶなど対応が弱い          |

| 日本語表現                   | 「選びたった」など不自然な言葉がある。掲載した生出力は訂正していない                                             |

人物の優劣や架空の業績数値を断定する出力は、この最終評価の**表示を許可した24回**では見つかりませんでした。少数ケースでのエージェント点検であり、捏造を防げるという保証ではありません。

## 改善の経緯

- v7：引用は正しくても、レビューの内容を説明した回答に「説明がない」と指摘する失敗があった。
- v8：振り返りを引用＋確認質問へ変更。28回の形式検証は通ったが、指示語を確認しない、命令文を質問の根拠にする、短い回答へ抽象的に問い返す問題が残った。
- v9：指示を強めても命令文の混入は残った。28回の形式成功を品質成功と判断しなかった。
- v10：既知の命令・数値付き採点表現を表示前に拒否し、指示語には対象を確認する質問例を与えた。24回通過、4回拒否。短い回答の振り返りなどは継続課題。

## 再現範囲

モデル取得後は、アプリ・Ollama・評価プロセスにmacOSの外部通信禁止プロファイルを適用しました。外部へのTCP接続が拒否され、loopbackへの接続が成功することを別途確認しています。PC全体のネットワーク設定は変更していません。

通常のVitestとPlaywrightはモデルを呼ばず、Ollama互換の合成応答を使います。引用拒否・二重送信・中断・保存失敗等のアプリ動作の検証であり、生成品質の証拠には数えません。実モデルを使う回帰・ブラウザー検証は別スクリプトで実行します。
